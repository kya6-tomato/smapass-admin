# FR-P01 ログイン

- 優先度：Must（段階1）
- タスク：T-03
- 使うAPI：`POST /auth/login`、`POST /auth/logout`、`GET /me`

## 目的

固定のデモアカウントでログインし、記録画面を使えるようにする。本番の本人確認（登録修理業者制度）は作らない。

## 画面

- `/login`：ID、パスワード、ログインボタン
- ログイン後のヘッダー：事業者名と種別、ログアウトボタン

## 受け入れ基準

1. デモアカウントのIDとパスワードでログインでき、記録画面に移る。認証の判定はGoが行い、サイトはIDとパスワードを持たない
2. IDかパスワードが違うときは「IDまたはパスワードが違います」と表示し、どちらが違うかは出さない
3. ログイン状態は httpOnly・Secure・SameSite=Lax のCookieで持ち、`document.cookie` から読めない
4. 未ログインで記録画面などを開くと `/login` に移る
5. ログアウトするとCookieが消え、記録画面を開くと `/login` に移る

## やらないこと

- 新規登録、パスワード再設定、「ログイン状態を保持」
- ログイン試行回数の制限（Go側の担当）

## テスト

- E2E：基準1〜5を1本ずつ（モック使用）
- 開発環境（http://localhost）ではSecure属性の扱いを確認する（Secure付きCookieはlocalhostでは多くのブラウザで許可されるが、T-03で実際に確かめる）
